
# Superstore Sales Analysis | Power BI Dashboard

## 📊 Project Overview

This project focuses on analysing Superstore sales data using Microsoft Power BI.

The objective is to transform raw business data into meaningful insights through data analysis, visualisation, and an interactive dashboard to understand sales performance, profitability, customer behaviour, product performance, and returns.

---

## 🎯 Project Objectives

- Analyse overall sales and business performance.
- Identify top-performing and underperforming products.
- Analyse sales across categories and sub-categories.
- Understand customer and segment performance.
- Analyse regional sales performance.
- Evaluate shipping modes and order trends.
- Analyse product returns.
- Create an interactive dashboard for business decision-making.

---

## 📁 Dataset Description

The source dataset contains four tables:

| Table | Records | Description |
|---|---:|---|
| Orders Data | 9,994 | Order details, dates, sales, quantity, discount, shipping mode, customer ID and product ID |
| Products | 1,870 | Product details, categories, sub-categories and cost |
| Customers | 793 | Customer details, segments, gender and geographical information |
| Returns | 292 | Return information, return dates, return reasons and product IDs |

---

## 📈 Business Questions

1. What is the overall sales performance?
2. Which product categories generate the highest sales?
3. Which sub-categories are performing well or poorly?
4. Which regions contribute the most to sales?
5. Which customer segments generate the most revenue?
6. How do shipping modes affect order distribution?
7. What are the trends in sales over time?
8. Which products or categories have higher return activity?
9. How do discounts relate to sales performance?
10. Which areas of the business require improvement?
